# BMI Calculator

An offline-first BMI calculator delivered as a hybrid Android application. Ionic React renders the mobile interface in a Capacitor WebView, while Capacitor Android packages it as an installable native Android app. Calculations and personal data stay on the device; there is no account, server, or network dependency at runtime.

## Features

- BMI calculations for centimeters, meters, feet/inches, kilograms, and pounds.
- Adult BMI categories, healthy-weight range, visual scale, and context-aware result notes.
- Locally saved calculation history with individual/all-delete controls and a progress chart.
- Editable profile, preferred units, and persistent light/dark appearance.
- Offline storage through Capacitor Preferences, plus accessible input validation and Android back navigation.
- About screen covering the formula, adult classification ranges, limitations, and medical disclaimer.

BMI is a screening measure, does not directly measure body fat, and does not diagnose medical conditions. Adult categories are intended for people aged 20 or older. Children and teens need age- and sex-specific percentile interpretation.

## Technology

- Ionic React 8, React 19, TypeScript, and Vite
- Capacitor 8 with Android, Preferences, Splash Screen, Status Bar, and App plugins
- Android Gradle project generated by Capacitor (`com.wellnest.bmicalculator`)

## BMI formula

- Metric: weight in kilograms divided by height in meters squared.
- Imperial: weight in pounds multiplied by 703, divided by height in inches squared.
- Adult healthy-weight range: 18.5 × height² to 24.9 × height², with height in meters.

Full precision is used for calculations; values are rounded for display.

## Requirements

- Node.js 20.19+ or 22.12+, npm, and Java 21 for Android builds.
- Android Studio with Android SDK Platform 36, Android SDK Build-Tools, and Platform-Tools.
- An Android emulator configured in Android Studio or a physical Android device for on-device testing.

## Run and test

```sh
npm install
npm run dev
```

The Vite development server prints its local URL. Run the BMI logic tests and production build with:

```sh
npm test
npm run build
```

Generate Android launcher and splash resources from `assets/icon.svg` with:

```sh
npm run assets:generate
```

## Android Studio and APK

Create the Capacitor Android project once, then build and sync the web assets:

```sh
npm run android:add
npm run android:sync
npm run android:open
```

In Android Studio, select an emulator and press **Run** to launch the app. For a debug APK, use **Build > Build Bundle(s) / APK(s) > Build APK(s)**, or run:

```sh
cd android
./gradlew assembleDebug
```

The resulting APK is `android/app/build/outputs/apk/debug/app-debug.apk`. Install it on a connected device with USB debugging enabled:

```sh
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

Set `JAVA_HOME` to a JDK 21 installation and `ANDROID_HOME` / `ANDROID_SDK_ROOT` to an Android SDK installation before building from a terminal. The Gradle wrapper downloads its required Gradle distribution on first use.

The application itself is offline-first. Android SDK and Gradle downloads are needed only to develop/build it.

## Source archive and sharing

Create a source ZIP from the project root (generated dependencies and build output are excluded):

```sh
zip -r bmi-calculator-source.zip . -x 'node_modules/*' 'dist/*' 'android/.gradle/*' 'android/app/build/*' 'artifacts/*' '*.apk' '*.zip' '.git/*'
```

Upload the ZIP and APK to Google Drive and set link access to **Anyone with the link**, or push the source to a GitHub repository and attach the APK and ZIP to a GitHub Release. Verify the sharing permissions in a private browser window before submitting the links.
